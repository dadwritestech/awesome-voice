    How the grade works

    Every rule was counted in two piles of text: answers from local models to 20 everyday writing prompts, and READMEs and release notes from 85 well-known open-source projects as they stood before June 2022, months before ChatGPT.

    A phrase becomes a rule only if models write it at least three times as often as those people did, or if people almost never write it at all. The grade is tells per 100 words, cut at the human documents' own spread.

    Fix it where you write

    The same checker runs as a Claude Code plugin. After your agent writes a Markdown file, it reads the marks and rewrites those lines before you see them.

    /plugin marketplace add dadwritestech/awesome-voice
/plugin install no-slop@awesome-voice

    Or check files from the command line, and fail CI on a bad grade:

    npx no-slop --max-grade B README.md
    Rules and counts are open: EVIDENCE.md. A mark is a hint, not a verdict; quoted text, names and technical terms can stay. MIT licensed.
